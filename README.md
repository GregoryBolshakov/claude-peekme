# claude-peekme

This moved into [peekme](https://github.com/GregoryBolshakov/peekme). Since 0.2.0 peekme works
with Claude Code and Codex CLI, so one tool covers both.

```
cargo install peekme
peekme install
```

After this, typing `claude` opens Claude Code with peekme. Select text, press Alt+P, and a short
explanation opens right next to it.

This repository is kept read-only for history.
